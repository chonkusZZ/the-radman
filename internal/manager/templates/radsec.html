How it works

  • The access point connects to the node on TCP {{.Port}} using TLS and presents a client certificate. No shared secret travels over the network (the protocol fixes it to radsec).
  • The key pair is generated in your browser; only the certificate request (public key) is sent here. The private key is never sent to or stored on the server, and is wiped from the page after you have saved it.
  • Revoking a certificate here disconnects the AP from the node within about a minute.
{{if .CanWrite}}

Generate a certificate

Needs a modern browser (WebCrypto). The page must be served over HTTPS.

Generating…

  1. Download the three files and upload them to the access point's RadSEC settings: its private key, its certificate and the CA that signed the node's server certificate.
  2. Point the AP's RADIUS server at the node: {{if .Public}}this site's node IP{{else}}the node IP{{end}}, TCP {{.Port}}, RadSEC/TLS enabled.
  3. Press Wipe key now once the files are saved.

The private key has been wiped from this page. If you didn't save it, generate a new pair — the certificate above is useless without it.
